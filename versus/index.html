Decisions

The questions people actually ask

Nobody searches “what is Flow.” They search “Flow vs Apex trigger.” Each page here takes one recurring decision, lays out the options in a matrix, and commits to a rule of thumb — saying “it depends” only where it genuinely does, and then saying on what.

  • Flow vs Apex trigger vs scheduled & batch

    A record changes and something else needs to happen. Where does the automation live?

  • Lookup vs master-detail vs junction

    Two objects need to be related. Is this a loose pointer, an owned child, or a many-to-many?

  • Profile vs permission set vs permission set group

    A user needs access to something. Where does that permission live?

  • Import Wizard vs Data Loader vs Bulk API vs integration

    Records need to get into Salesforce. Is this a one-off, a migration, or a pipe that has to keep running?

  • Change sets vs DevOps Center vs scratch orgs vs unlocked packages

    Metadata needs to move from one org to another. What is the vehicle?

  • Prompt template + Flow vs Agentforce

    Something in the org should use a large language model. Is this a prompt on a deterministic path, or an agent that gets to choose?

Each page links back to the full topic dives. If a decision you keep having is missing, that is a content bug — the catalog should cover the ones that generate Slack threads.
